SCOPE AND BEHAVIOR
- YouTube URL storage only; no uploads, embeds, external metadata fetches or API credentials.
- Watch/short/share/mobile/live/embed addresses normalize to a canonical watch URL.
- Student curriculum enrollment is authoritative; an optional level must be in
  that enrollment's journey, and the optional Lesson must belong to that level.
- Default visibility: internal. The share checkbox publishes both link and note
  to students/parents who already have academic access.
- Existing mutation boundary preserved: SUPER_ADMIN. No new grants to branch
  administrators, teachers, finance, students or parents.
- Assigned teachers use the existing academic-read authorization function.
- Parent/student access uses existing academic permission and relationship checks.
- VIBE sharing never grants/revokes YouTube access. Video existence/privacy is
  not automatically verified. Private YouTube videos may require Google login.
- No writes to lesson completion, grades, scores, attendance, tuition or Zalo.
- Duplicate canonical URL within an enrollment is rejected. Versions prevent
  stale edits/removals. Removal is soft deletion; event history records the actor.
- User text is escaped. Only normalized HTTPS YouTube links become anchors;
  external links use noopener/noreferrer and no referrer.
- Validation errors preserve entered values.
