## Rules

1. Codex must read relevant decision records before implementation.
2. Decision records override assumptions made in older chat discussions.
3. If a newer approved decision conflicts with an older specification, the newer decision record wins.
4. Do not invent a business rule where owner approval is still required.
5. Any superseded decision must remain in Git history for auditability.
